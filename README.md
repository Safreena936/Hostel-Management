# 🏠 Hostel Management System

## 📖 Project Overview

The Hostel Management System is a web-based application developed to simplify and automate hostel administration tasks. The system provides a centralized platform for managing student information, room allocations, hostel records, and user authentication. It reduces manual paperwork and improves the efficiency of hostel management.

## ✨ Features

* Admin Login and Authentication
* Student Registration and Login
* Student Profile Management
* Room Allocation Management
* Hostel Occupancy Tracking
* Secure Session Handling
* Database-Driven Record Management
* User-Friendly Interface
* CRUD Operations (Create, Read, Update, Delete)

## 🛠️ Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Server: XAMPP / Apache

## 🚀 How to Run

1. Install XAMPP and start Apache & MySQL.
2. Copy the project folder into the `htdocs` directory.
3. Create a MySQL database (e.g., `hostel_db`).
4. Import the SQL file into the database.
5. Update database credentials in `config.php`.
6. Open your browser and run the project through localhost.
